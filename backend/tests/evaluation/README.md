# Voice-01 合成需求回归评测

`voice01_eval.py` 固定了 PR #1 审查中的 50 条合成输入，包含名称、别名、类别、约束、否定、歧义、无关问题、ASR 错字和提示注入。案例由审查者编写，**没有独立人工真值标注，不是正式精度基准**；名称和候选受珠海 OSM 数据覆盖影响。不得将模型、OSM 原始文件、用户数据或输出中的地图数据提交 Git。

准备本地 Ollama `qwen2.5:7b`，使用项目脚本基于已授权的珠海 OSM 生成 `search-poi.geojson`，从仓库根目录运行：

```bash
PYTHONPATH=backend backend/.venv/bin/python backend/tests/evaluation/voice01_eval.py /tmp/voice01-new-results.jsonl
```

输出路径必须不存在；每条记录包含合成输入、经验证的意图、候选、错误及耗时。本脚本不发送音频、不调用腾讯云，也不保存完整模型原始输出。`origin` 未提供，以验证位置约束在缺少依据时的安全行为。

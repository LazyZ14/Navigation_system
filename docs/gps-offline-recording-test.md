# GPS 离线录制 - 15 分钟室外测试手册

## 前置条件

- iPhone 已安装 GpsSender App（最新 build）
- iPhone 电量充足
- 室外开阔区域（避免高楼遮挡）

## 测试步骤

### 1. 启动离线录制（室内，1 分钟）

1. 打开 GpsSender App
2. 在顶部选择 **"离线录制"** 模式
3. 点击 **"开始录制"** 按钮
4. 确认状态显示 **"录制中"**
5. 等待第一个定位样本出现（通常 5-10 秒）

### 2. 室外步行测试（10 分钟）

1. 携带 iPhone 到室外开阔区域
2. 正常步行或慢跑，保持手机在前台（屏幕亮着）
3. 偶尔查看 App，确认：
   - **样本数** 持续增加
   - **最近定位时间** 在最近几秒内
   - **错误数** 为 0 或很少

**建议路线：**
- 直线行走 200-500 米
- 转弯继续行走
- 如有可能，经过一些建筑物附近（测试多路径效应）

### 3. 停止录制（回到室内，1 分钟）

1. 点击 **"停止并保存"** 按钮
2. 确认状态显示 **"已保存 X 个样本"**
3. 记录样本数和录制时长

### 4. 导出轨迹文件（1 分钟）

1. 在 **"已保存的轨迹"** 列表中找到最新的文件
2. 点击分享图标（方框加箭头）
3. 选择以下任一方式导出：
   - **AirDrop** 到 Mac
   - **保存到 Files** App
   - **邮件** 发送给自己

### 5. Mac 端分析（2 分钟）

在 Mac 上打开终端，运行：

```bash
cd /path/to/Navigation_system
python3 scripts/analyze_gps_recording.py /path/to/exported/file.jsonl
```

**关键指标检查：**
- **总样本数** > 50（10 分钟至少应有 50+ 样本）
- **平均采样间隔** < 2s（理想值 0.2-1s）
- **P95 采样间隔** < 5s
- **平均定位年龄** < 5s
- **平均精度** < 20m（开阔区域应 < 10m）
- **长间隔 (>10s)** 应很少或没有

## 预期结果

| 指标 | 良好 | 可接受 | 需改进 |
|------|------|--------|--------|
| 采样率 | >1 Hz | 0.5-1 Hz | <0.5 Hz |
| 平均精度 | <10m | 10-20m | >20m |
| 定位年龄 | <2s | 2-5s | >5s |
| 长间隔 (>10s) | 0 | 1-3 | >3 |

## 常见问题

**Q: 样本数不增加？**
A: 检查定位权限是否授予，确认在室外开阔区域。

**Q: 错误数很多？**
A: 可能是定位信号弱，尝试移动到更开阔的地方。

**Q: 文件导出失败？**
A: 确认文件已保存（停止录制后再导出），检查存储空间。

**Q: 分析脚本报错？**
A: 确认文件路径正确，文件格式为 JSONL（每行一个 JSON 对象）。

# iPhone USB GPS 人工联调

## 准备

使用 iOS 16+ 真机与 Xcode，安装 `ios/GpsSender/GpsSender.xcodeproj`。允许「使用 App 期间」定位、「精确位置」与「本地网络」。连接 USB 并开启个人热点，在 Mac 网络设置确认 iPhone USB 的 IP；不要把手机自身地址误填为 Mac 地址。

## 服务与配置

按 [README](../README.md) 创建 `.env.gps.local` 并启动前后端。设备 ID 与随机令牌必须和手机相同。不要提交环境文件，不要把真实令牌粘到报告中。容器默认只允许本机连接；手机接入需明确设置 `GPS_LAN_BIND_ADDRESS` 为 Mac 对应网卡 IP。

手机选择「实时发送」，填写 Mac IP、后端端口 `8000`、设备 ID/令牌，保持 App 在前台。浏览器打开 `http://127.0.0.1:5173/amap.html?mode=live`。

## 检查

- 「正在发送」表示定位已启动，不代表上传成功；「已发送 #序号」才表示一次成功响应。
- 后端收到 `POST /api/gps/fixes` 返回 `202`；序号持续递增，在线快照更新，浏览器订阅 `/ws/gps/live`。
- 精度必须在 100 米以内才能更新车辆位置；精度约千米时先检查精确位置权限和信号条件。
- 超过 10 秒无新定位会判离线。0.2 秒仅为最小发送间隔，不保证定位采样频率。
- 停止后重新发送应创建新流；模式切到 Demo 后，手机更新不应覆盖 Demo 小车。

只有明确进行道路测试时才验证正常推进、无可达路线、路外/低精度噪点和偏航节流重算。请勿把真实轨迹或坐标作为仓库测试数据。

## 停止

在服务终端按 Ctrl+C；容器使用 `docker compose down`。iOS 离线录制功能仍保留，导出分析见 [录制指南](gps-offline-recording-test.md)。
